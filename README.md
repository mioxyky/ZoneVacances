ZoneVacances is a website that lets you check school holiday dates in France and Belgium. Find out when your next holidays are and compare dates with your friends to see if you'll be on holiday at the same time! 

## Launch the project

```bash
npm install
npm run dev
```

App available subsequently on `http://localhost:3000`.

## Data sources

- `Education France` - Official school calendar
- `calendrier.api.gouv.fr` - Public holidays in France
- `OpenHolidays API` - Holiday and public holiday data for Belgium
- `API Geo` - Geographical research in France
